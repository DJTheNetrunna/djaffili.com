# Amazon Associates Starter Website

## Files
- `index.html`
- `styles.css`
- `script.js`

## How to use it

1. Open `index.html` in your browser.
2. Search the project for:
   `YOUR_AMAZON_AFFILIATE_LINK_HERE`
3. Replace each placeholder with your actual Amazon Associates product link.
4. Replace the example products and descriptions with products you actually recommend.
5. Upload the three files to a web host such as GitHub Pages, Netlify, Vercel, or your own hosting account.

## Important

Keep the affiliate disclosure visible. Make sure your site and links comply with the current Amazon Associates Program Operating Agreement and applicable advertising/disclosure rules.

Do not copy Amazon product photos, prices, ratings, or other Amazon content unless your permitted Amazon Associates tools/API allow that usage.
